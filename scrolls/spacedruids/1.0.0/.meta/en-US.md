name: SpaceDruids
description: Defend the galaxy in a Rust-powered browser arcade. Play directly in the deployment UI or share its public page.
---

A single-player SpaceDruids arcade built with Rust WASM and Druid UI's typed Canvas, keyboard, animation and audio APIs. No game installation is needed.

Move with **Arrow keys / A / D**, fire with **Space**, pause with **P**, restart with **R**, and toggle sound with **M**. Click the arena to focus keyboard controls. Three lives, destructible bunkers, enemy waves and a session high score are included.

The game runs in each visitor's browser, not on the server. Publishing the public UI lets anyone play independently without deployment access. The deployment contains the editable Rust source and a build command for both UI scopes.
